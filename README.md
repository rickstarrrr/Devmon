# Devmon Game
A browser-based monster-catching and strategy game built for the web.

# About
Devmon Game is a lightweight, browser-playable game where players collect, evolve, and battle creatures called Devmons. It is designed to be quick to launch and easy to play in a browser.

# Features
Collect and manage Devmons
Battle enemies using strategy
Explore a simple game loop
Play directly in the browser
Designed for quick sessions and easy access

# How to play
Open the game in your browser using the link above.
Start a new run or session.
Choose your Devmon and begin exploring.
Use the in-game actions to battle, collect, and progress.
Continue building your team and improve your strategy.

# Controls
Mouse: select cards, buttons, and game actions
Keyboard: use keys as shown in the game UI
Touch: supported if your browser/device supports it
